# agy-mcp

English | [简体中文](README_CN.md)

`agy-mcp` is a local MCP server for Google Antigravity CLI (`agy`).

## Tool

The server exposes one MCP tool:

- `agy`: invokes Antigravity CLI and returns a resumable `SESSION_ID`.

Public parameters:

- `PROMPT`: instruction sent to `agy`.
- `cd`: working directory for the `agy` process.
- `SESSION_ID`: resume a specific Antigravity conversation; empty starts a new session.
- `sandbox`: pass `--sandbox` to `agy` for this call. Defaults to `false`.
- `return_all_messages`: return MCP-friendly event records. Defaults to `false`.
- `model`: specify a model; only pass this when the user explicitly requests it.

## Install

The executable wrapper is generated by chezmoi at `$HOME/.local/bin/agy-mcp`.

MCP client config:

```toml
[mcp_servers.agy-mcp]
command = "agy-mcp"
startup_timeout_sec = 60
tool_timeout_sec = 1800
```

The wrapper always runs the project from `$HOME/.agent/mcp/agy-mcp`:

```bash
uv run --directory "$HOME/.agent/mcp/agy-mcp" --locked python -m agy_mcp.cli
```

`agy` must already be installed and authenticated. This project does not read or copy credential files.

## Environment

```bash
AGY_BIN=agy
AGY_MCP_TIMEOUT_SECONDS=1200
```

## Sessions

First call:

```json
{
  "PROMPT": "Inspect this repo and summarize the build system.",
  "cd": "/path/to/repo"
}
```

Response:

```json
{
  "success": true,
  "SESSION_ID": "c39b574d-1ba0-43a0-91bf-73848219b04f",
  "agent_messages": "..."
}
```

Continue a session:

```json
{
  "SESSION_ID": "c39b574d-1ba0-43a0-91bf-73848219b04f",
  "PROMPT": "Continue from the previous analysis.",
  "cd": "/path/to/repo"
}
```

`SESSION_ID` is the real Antigravity conversation UUID, not a local MCP-generated id. Continued calls pass it to `agy --conversation=<SESSION_ID>`.

## Sandbox

`sandbox` is a per-call MCP tool parameter, not an MCP server startup setting.

```json
{
  "PROMPT": "Run tests in this repo.",
  "cd": "/path/to/repo",
  "sandbox": true
}
```

When `sandbox: true` is passed, the generated command includes `--sandbox`.

## Implementation Notes

- The server always passes `--dangerously-skip-permissions` because MCP stdio has no interactive TTY approval flow.
- New calls discover the real `SESSION_ID` from Antigravity conversation state after `agy --print` returns.
- Continued calls use the officially supported `--conversation=<SESSION_ID>`.
